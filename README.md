# bili-helper · B 站增强助手

网页版哔哩哔哩（bilibili.com）的浏览器增强扩展，核心是一套 **AI 助手**，配合界面净化、视频过滤、布局与体验优化。自用优先，源码工程化重建中。

> ⚠️ 当前仓库处于**重建初期**：原项目为打包压缩产物（无源码），现已决定用 WXT + TypeScript 重建源码工程，首期聚焦 **AI 助手 + 工程地基**，其余功能按需逐步迁移。

---

## ✨ 功能总览

### 🤖 AI 助手（当前重构重点）

| 功能 | 说明 |
| --- | --- |
| **AI 去广告** | 自动识别视频中的「恰饭 / 带货」片段并跳过。采用**混合检索 RAG**（词表/BM25 + 向量 + RRF 融合 → LLM 精确定界），比全文丢给 LLM 更省 token，命中更准 |
| **视频总结** | 结构化输出：一句话概括 / 核心要点 / 关键术语 / 可复习时间线 |
| **AI 提问** | 基于当前视频字幕、弹幕、评论上下文的问答，带来源标注 |
| **字幕润色** | 修正字幕错别字、断句与口语冗余，输出成文 |

**接入方式**：直连自定义 OpenAI 兼容端点（本地 / 自建服务器双后端可切换），彻底去官方平台依赖 —— 不经过任何第三方中转，API Key 只发给你自己配置的地址。

### 🔎 视频过滤

- **视频筛选**（按标签 / 关键词）
- **广告视频**、**推广视频**、**标签视频**过滤屏蔽

### 🎨 界面净化与布局

- 贴片广告隐藏、元素隐藏
- **无级倍速**、全屏进度条
- **左右分屏**、右侧评论、极简首页
- **极速预览**、封面放大、评论 IP 归属显示
- 界面颜色主题切换

## 🛠 技术栈

| 层 | 选型 |
| --- | --- |
| 扩展框架 | [WXT](https://wxt.dev/) + TypeScript |
| UI | Vue 3 + UnoCSS（内容注入用 Shadow DOM 隔离） |
| Markdown 渲染 | marked |
| 包管理 | pnpm |
| 向量检索 | 自定义端点 `/embeddings`（OpenAI 兼容），BM25 + 向量 + RRF 混合召回 |

## 📁 目录结构（规划）

```
entrypoints/
  content/    # 内容脚本：数据采集 + AI 能力 + 总结/去广告 UI
  options/    # 设置页（端点 / embedding / server 配置）
  popup/      # 弹窗
  background/ # service worker
modules/      # 核心逻辑：ai / video / settings
```
