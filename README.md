# bili-helper · B 站增强助手

网页版哔哩哔哩（bilibili.com）的浏览器增强扩展。在不多打扰你的前提下，把 B 站变得更清爽、更快、更顺手：过滤不想看的视频、净化页面广告、优化播放器体验，并内置一套 **AI 助手**，帮你识别并跳过恰饭广告、总结视频、就视频内容提问。

---

## 🤖 AI 助手

打开任意视频，右侧会注入一个 AI 面板，含「总结 / 提问」两个标签页。

### 自动跳过恰饭广告

自动识别视频里「恰饭 / 带货」片段（通常 3 秒前开始提示）：

- 播放器顶部弹出提示条，显示商品名、累计已节省时长；
- **3 秒倒计时后自动跳过**该片段继续播放——什么都不点也会跳；
- 也可以点「马上跳」立刻跳过，或「这段想看」留在原地；
- 识别出的广告片段会在进度条上打标记，并在「总结」的分段列表里标出「广告」。

### 视频总结

基于字幕生成 Markdown 总结正文，下方附一份「视频分段」时间线：每段显示起止时间和标题，**点击即可跳到对应时间点**，广告段带专属标签。

### AI 提问

围绕当前视频的 AI 对话：会预置推荐问题（内容是什么、精华片段、重要结论、怎么安利给朋友），也支持自由提问，全程基于视频的字幕上下文回答，流式输出并在相关处标注字幕时间点、点击即可跳播。

## 🔎 过滤视频

作用于 B 站首页，自动把你不想看的内容挡在信息流之外：

- **视频筛选**：按标题关键词、作者黑名单、时长、弹幕/点赞/播放量、点赞率、发布日期等规则隐藏视频；
- **广告视频**：隐藏带「广告」标识的商业推广；
- **推广视频**：隐藏「小火箭」标识的推广 / 充电视频；
- **标签视频**：隐藏直播、番剧、综艺、课堂等非普通视频卡片。

## 🎨 界面净化

作用于全站，让页面更干净：

- **贴片广告**：精准隐藏各类横幅、贴片等已知广告区域；
- **隐藏元素**：按可配置规则隐藏页面上任意元素（如搜索栏推荐文字）。

## 🖥 布局优化

作用于视频播放页和首页：

- **左右分屏**：播放器控制栏新增「左右分屏」按钮，左侧沉浸式播放，右侧承载详情 / 合集 / 评论 / AI 助手 / 弹幕 / 推荐面板；
- **右侧评论**：把评论区自动搬到播放器右侧，边看视频边刷评论；
- **极简首页**：把首页重构为只剩搜索框，彻底屏蔽信息流，支持自定义背景图。

## ⚡ 功能增强

- **极速预览**：鼠标悬停视频卡片弹出预览，左右滑动实时拖动预览进度，快速判断值不值得看；
- **无级倍速**：接管播放器倍速，0.1x–5.0x 滑杆无级调节，一次设置持续生效；
- **全屏进度条**：全屏播放时底部进度条常显；
- **优化加载**：滚动接近底部时预加载下一批推荐，减少等待；
- **封面放大**：卡片封面悬停出现放大镜，一键在新标签页查看原始大图；
- **换一换历史**：记录首页「换一换」的刷新历史，支持前进 / 后退与页码提示；
- **评论 IP 归属**：在每条评论用户名旁显示其 IP 属地。

### AI 去广告是怎么做的

去广告是全项目技术含量最高的一环——**核心问题不是"有没有广告"，而是怎么用最少的 token、最快的速度，把字幕+弹幕里多出来的那段"恰饭"精准定位出来**。如果直接把整段字幕和几千条弹幕一股脑丢给大模型，既慢又费钱。

所以采用 **混合检索 RAG + LLM 精确定界** 两段式：

```text
视频字幕(按窗口切块) ──┬─► 词表/BM25 精确匹配 ──┐
                        │   (品牌词、"恰饭/团购"等字面信号) │
                        │                              ├─► RRF 融合排序 ─► 候选广告窗口
                        └─► 向量语义检索 ──────────────┘
                              (自定义端点 /embeddings，抓黑话、变体、新梗)
                                    │
                                    ▼
                           LLM 精确定界(只喂候选窗口±上下文)
                           → 输出 {start, end, 商品名, 置信度}
```

四个关键点：

1. **混合检索**：词表/BM25 抓「字面精确命中」（品牌名、"赞助""团购"），向量抓「语义变体」（黑话、委婉说法、新梗），两条路互补后用 RRF（倒数排名融合）合并排序——单一方式都覆盖不了广告话术的多样性。

2. **父子窗口（small-to-big）**：先用小窗口（约 30 秒）召回"疑似广告"，命中后再回取父级大窗口（±N 秒上下文）喂给 LLM，让它在足够上下文里定出精确起止时间——而不是让模型自己漫无边际地找。

3. **LLM 精确定界**：模型只处理候选窗口，输出结构化的广告起止时间、商品名和置信度；结果驱动进度条标记和自动跳过。

4. **降级链**：自定义端点不支持 `/embeddings` 时自动退化为纯词表检索；再失败则兜底直连 LLM 全量分析——保证任意 OpenAI 兼容端点都能用。

**向量缓存**：语料向量与视频窗口向量都缓存在本地，键上标注「embedding 模型 + 端点地址 + 语料版本」，换模型或改语料会自动失效重算，避免不同向量空间混用。

### AI 端点接入

去广告、总结、提问全部**直连你自己配置的 OpenAI 兼容端点**（本地 / 自建服务器可切换），不经过任何第三方中转——API Key 只发给你指定的地址。

## 📄 安装与使用

1. 安装依赖：`pnpm install`；
2. 源码构建：`pnpm dev`（开发构建，`.output/chrome-mv3`）或 `pnpm build`（生产构建；`pnpm zip` 额外打包 zip）；
3. 打开浏览器的扩展管理页，开启「开发者模式」；
4. 选择「加载已解压的扩展程序」，指向 `.output/chrome-mv3` 目录；
5. 打开 bilibili.com，在扩展设置页按需开启功能、配置 AI 端点。

补充：`pnpm dev` 会在开发模式下热更新产物，改完代码重载扩展即可；`pnpm test` 跑单元测试。
